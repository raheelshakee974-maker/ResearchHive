# ResearchHive - Multi-Agent Research Assistant

## Setup
1. Python 3.10+ install karein
2. `pip install -r requirements.txt`
3. Free API key: https://aistudio.google.com/apikey
4. `.env.example` ko `.env` rename karein aur key paste karein (ya app ke sidebar mein paste karein)
5. `streamlit run app.py`

## Agents
Planner -> Researcher (DuckDuckGo + Gemini) -> Analyst -> Fact-Checker -> Writer
